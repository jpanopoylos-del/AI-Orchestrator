How to use Claude Code

Claude Code is an AI coding assistant that works directly in your project. Once it's installed, open a terminal in your project folder and run `claude`, then describe what you want in plain language, for example "fix the failing login test" or "add a dark mode toggle to the settings page". Claude reads the relevant files, proposes edits, and can run commands such as your tests or build, asking for your permission before it changes files or runs anything risky. Review each change as it comes and redirect it whenever you like. To give it lasting context about your project, such as coding conventions or how to run tests, add a CLAUDE.md file at the project root. For workflows you repeat, save a prompt as a custom slash command in .claude/commands/, or define specialised helpers as subagents in .claude/agents/, which is exactly how this repository's /orchestrate command and its researcher, implementer and reviewer agents are set up. Type /help inside a session to see what's available.
